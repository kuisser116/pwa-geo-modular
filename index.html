¿Para qué usamos tu ubicación?

Queremos adjuntar las coordenadas al reporte técnico y calcular la zona más cercana. La lectura se procesa en este dispositivo y no se envía a ningún servidor.

  • El navegador te pedirá permiso justo después de confirmar.
  • Si lo rechazas, puedes elegir una zona manualmente.
  • Puedes consultar la ubicación solo cuando tú lo decidas.

Elegir una zona manualmente

Si no hay GPS, rechazaste el permiso o la lectura tardó demasiado, puedes usar una zona de referencia.

Para reactivar el permiso: abre el candado de la barra de direcciones y permite la ubicación para este sitio.

La ubicación se usa solo en este dispositivo.
